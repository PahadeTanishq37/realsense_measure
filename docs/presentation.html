Slide 1 • Overview

Multi-View 3D Point Cloud Scanning System

We have designed and implemented an end-to-end multi-view 3D scanning system using the Intel RealSense D455 depth camera that captures, filters, registers, and fuses multiple angle point clouds into a single coherent 3D model.

1. Real-Time Acquisition
Implemented hardware-filtered RGB-D acquisition with spatial, temporal, and decimation filtering to suppress depth sensor noise.
2. Spatial Isolation
Built an automatic segmentation module that removes table/floor background planes via RANSAC and isolates target clusters using DBSCAN.
3. Multi-View Alignment
Engineered dual-path registration (FPFH+ICP and RGB-D Odometry+Colored ICP) optimized with Levenberg-Marquardt Pose Graphs.
Current Milestone: Full multi-view 3D point cloud reconstruction is fully working and verified. Consecutive viewpoints align accurately without drift, producing clean, watertight 3D point clouds.
Slide 2 • Implementation

Technical Stack & Algorithms by Stage

Every stage of our pipeline is backed by specific computational geometry algorithms and libraries:

Stage 1: Capture
Hardware: Intel RealSense D455
Library: pyrealsense2, OpenCV
Filters: Decimation, Spatial Smooth, Temporal Averaging, Hole Filling
Stream: 848x480 @ 30fps aligned
Stage 2: Isolation
Framework: Open3D, NumPy
Plane Removal: RANSAC Plane Fit
Clustering: DBSCAN (eps=20mm)
Denoising: Statistical Outliers (SOR)
Tracking: Centroid distance gate
Stage 3: Registration
Features: 33D FPFH Descriptors
Global: RANSAC Feature Match
Local ICP: Point-to-Plane & Colored
Tracking: RGB-D Hybrid Odometry
Optimization: Pose Graph (LM)
Stage 4: Reconstruction
Fusion: Uniform TSDF Volume
Grid: 3mm - 4mm Voxel Grid
Integration: Raycasting & SDF
Export: Standard .PLY format
Viz: Open3D Multi-Camera GUI
Slide 3 • Architecture Flowchart

System Execution Flow (Stage 1 ➔ Stage 5)

How data flows from initial stereo camera sensor input to the final reconstructed 3D point cloud:

Stage 1
RGB-D Capture
Acquires aligned color and depth frames; applies hardware denoising.
Stage 2
Plane Strip & Cluster
RANSAC strips table/floor; DBSCAN extracts target point cloud.
Stage 3
Multi-View Register
Pairwise ICP & Odometry align views into a shared pose graph.
Stage 4
TSDF Volumetric Fusion
Integrates depth rays into uniform voxel grid to eliminate overlap noise.
Stage 5
3D Point Cloud Export
Outputs full unified .PLY point cloud with RGB vertex color.
Robustness Gating Implemented
  • ▹ Motion Quality Gate: Rejects frame pairs with unnatural rotation jumps (>25°) or translation jumps (>150mm).
  • ▹ Loop Closure Checks: Automatically links distant overlapping frames to eliminate drift over full orbits.
Key Algorithmic Verification
  • ▹ Verified with synthetic known-motion test suite (RMSE < 1.5mm, rotation error < 0.5°).
  • ▹ Trajectory tracking verified across multi-frame continuous sweeps without drift.
